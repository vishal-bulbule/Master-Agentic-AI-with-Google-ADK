name: translate-to-french
description: Translates English text into French while keeping product names and technical terms in English. Use when the user asks for a French translation.
author: Vishal Bulbule
---

Step 1: Read `references/glossary.md` to get the list of terms that must stay in English.
Step 2: Translate the user's text into natural, formal French (use "vous").
Step 3: Keep every glossary term exactly as written in English.
Step 4: Reply with the French text only, then one line listing the glossary terms you kept.
