# Archived samples

These are the original samples from the
[Agentic AI with Google ADK YouTube playlist](https://www.youtube.com/playlist?list=PLLrA_pU9-Gz2HwepRUVpq1TEPuYWo_fSi),
recorded between October 2025 and February 2026.

They are kept here as recorded so the videos still match the code. They were
written for ADK 1.x and are not maintained or tested against current releases.
Model names such as `gemini-2.0-flash` in these folders may no longer be
available.

For current, tested code covering the same topics, use the modules at the
repository root:
